## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Indrajthakur/INDRA_PORTFOLIO.git
```

Navigate to the project:

```bash
cd INDRA_PORTFOLIO
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🔐 Admin Dashboard

The portfolio includes a dedicated administration dashboard powered by Supabase.

Administrators can manage:

- Profile information
- Technical skills
- Experience and education
- Featured projects
- Music playlists

Portfolio content is stored in Supabase, allowing updates without redeploying the website.

Database access should be protected using Supabase Row Level Security policies.

---

## 🌐 Deployment

This application is designed for deployment on Vercel.

```bash
npm run build
```

Configure the required Supabase environment variables in Vercel before deployment.
